## New Transaction Types

| Name | Type Code | Amendment | Notes |
| ---- | --------- | --------- | ----- |
| [Entropy](/docs/protocol-reference/transactions/pseudo-transaction-types/entropy) | 89 | RNG | Pseudo-transaction. Validators only. |
| [SetManifest](/docs/protocol-reference/transactions/transaction-types/setmanifest) | 91 | OnChainManifests | Unsigned, canonical envelope. Submit with `submit` and `manifest`. |

Changed: [AccountSet](/docs/protocol-reference/transactions/transaction-types/accountset#apploader) gains the optional `AppLoader` field (PWALoader). [SetHook](/docs/protocol-reference/transactions/transaction-types/sethook) validates `HookOnIncoming`/`HookOnOutgoing` more strictly (HookOnV2_1).

Fixes with possible client impact:

* **Subscriptions:** webhook (`url`) subscription delivery no longer stalls after HTTP errors from the receiving endpoint.
* **JSON-RPC:** idle HTTP keep-alive connections are no longer dropped prematurely.
* **Base58:** decoding now handles high-bit characters correctly (they are read as unsigned).

## Node Operator Behaviour

* **Amendment-blocked servers stop** instead of running degraded, and write a `README_AMENDMENT_BLOCKED` receipt to the config directory. See [Updating xahaud](/docs/infrastructure/updating-xahaud#amendment-blocked-servers-stop).
* **UNLReport reliability:** UNLReport generation is no longer blocked by the Negative UNL local reliability gate. See [Enabling Validation](/docs/infrastructure/enabling-validation#unlreport-reliability).
* Boost is updated to 1.91, and Beast/asio timeout bugs are fixed.
* Fixed a `ReportFeeChange` data race, queuing when there were no subscribers, and a LoadManager loop.
* Build fixes for clang-16 and for ARM (embedded tests hanging).
* `AMMCreate` fee calculation now includes Hook and multisign fees.

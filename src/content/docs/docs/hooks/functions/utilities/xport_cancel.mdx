### Behaviour

- Cancels a shadow ticket created by a successful Export transaction, including one that originated from a previous `xport()` call.
- The shadow ticket is deleted and its reserve is freed.
- It releases one of the account's bounded outstanding shadow-ticket slots.
- It does not revoke validator signature shares already published to the peer network.

<Aside type="caution">
A destination transaction may still execute after cancellation. Its returned XPOP cannot trigger the callback while the latch is absent. Use this resource-reclamation escape hatch only after external evidence such as target `LastLedgerSequence` expiry, destination Ticket consumption, or SignerList invalidation, or under an explicit recovery policy that accepts delayed target execution and callback replay. Otherwise import the target-chain proof to consume the shadow ticket.
</Aside>

If the destination SignerList requires a separate submission-authorizer key, the target-submission process can honor a validated cancellation by refusing to add its final signature. This protection applies only before that signature is broadcast or otherwise released.

### Definition

```c
int64_t xport_cancel (
    uint32_t ticket_seq
);
```

### Example

```c
int64_t result = xport_cancel(2);  // cancel shadow ticket for TicketSequence 2
if (result < 0)
    rollback(SBUF("Cancel failed"), 1);
```

### Parameters

| Name       | Type     | Description                                                    |
| ---------- | -------- | -------------------------------------------------------------- |
| ticket_seq | uint32_t | The ticket sequence of the shadow ticket to cancel.             |

### Return Code

| Type    | Description                                                                                   |
| ------- | --------------------------------------------------------------------------------------------- |
| int64_t | The cancelled ticket sequence on success. Check for `result >= 0`, not `result == 1`. If negative, an error: `DOESNT_EXIST` — no shadow ticket found for the specified ticket sequence on this account. |
